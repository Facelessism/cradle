How to use

  1. Add Node mode is on by default — click anywhere on the canvas below to place a node.
  2. Switch to Add Edge mode, then click two nodes in a row to connect them (you'll be asked for a weight).
  3. Pick an Algorithm and a Start node on the left, then press ▶ Play.
